# 展示素材

公开素材使用实际 Qt 界面渲染，配置来自新的默认 Config 对象，没有调用 Config.load 或读取运行中的私人配置。
英文例句及中文译文均为预设文案；这是一段界面/交互演示，不是联网翻译速度或准确率测试。

- `settings.png`：翻译设置。
- `result-card.png` / `live-caption.png`：结果与实时窗口。
- `demo.mp4`：40 秒、1920×1080、60fps，无声。
- `demo.gif`：翻译服务与实时设置片段的 18fps 精简预览；不代表应用刷新率。
- `demo-poster.png`：视频封面。

## 时间线

| 时间 | 内容 |
| --- | --- |
| 0–4 秒 | 软件与界面概览 |
| 4–13 秒 | 原文/译文结果卡片、复制反馈 |
| 13–23 秒 | 示例字幕更新、取景黄框开关 |
| 23–36 秒 | 翻译服务、接口顺序与实时设置 |
| 36–40 秒 | 项目与仓库入口 |

## 重现

安装项目依赖，并在本机准备 FFmpeg：

```powershell
python scripts/create_public_media.py --out docs/media --ffmpeg ffmpeg
```

导出进程使用固定时间线逐帧推进动效，以 60fps 编码。它不修改应用动效代码，也不用于测量运行帧率。
离屏合成时使用实际控件的 grab 绘制；取景框只保留可见绘制，不对视频合成应用鼠标穿透 mask。
素材没有录制私人桌面、真实 API 页面、浏览器账号或第三方视频画面。
